# پیام‌رسان بله (اختیاری)

صورت پروژه می‌گوید اتصال به **بله** هم شدنی است، با این شرط که **خودت** مستندات Bot API آن را پیدا کنی و بخوانی، و نگاشت را در گزارش بیاوری.
این‌جا فقط آماده‌سازی فنی را گذاشته‌ام؛ جزئیات بله را از مستندات رسمی خودش تأیید کن، چون من آن‌ها را بررسی نکرده‌ام.

## آنچه در کد آماده است

متغیر `BOT_API_BASE` (پیش‌فرض `https://api.telegram.org`) آدرس پایهٔ API ربات را تعیین می‌کند. تنها جایی که کد با پیام‌رسان صحبت می‌کند تابع `sendMessage` است:

```
POST {BOT_API_BASE}/bot{BOT_TOKEN}/sendMessage     body: {"chat_id": ..., "text": ...}
```

و ورودی webhook با شکل `update.message.{from.id, chat.id, chat.type, text}` خوانده می‌شود.

## اگر ساختار یکسان بود

۱) `BOT_API_BASE` را به آدرس پایهٔ بله تنظیم کن (در `[vars]` یا با `scripts/set-webhook.sh` از متغیر محیطی).
۲) `set-webhook.sh` را با توکن بله اجرا کن.
۳) اگر نام هدر secret یا شکل update متفاوت بود، فقط دو نقطه در `src/index.js` باید عوض شود: خواندن هدر در `webhook()` و استخراج فیلدها در `processUpdate()`. آن‌ها را عوض کن و تست‌ها را به‌روز کن.

**مهم:** برای امتیاز، هر تفاوتی که پیدا کردی و راه‌حلش را در گزارش بنویس.
